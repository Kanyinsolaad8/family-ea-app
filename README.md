# Family EA app

An iPhone home-screen app for the Family EA. It's free to run, private per person, and works in light and dark mode with adjustable text size and font.

- `app/` — the phone app (upload this folder to GitHub Pages)
- `backend/` — the Google Apps Script back end (paste into script.google.com)
- `docs/SETUP.md` — install steps, start here
- `docs/SCHEDULED_TASK_ADDITIONS.md` — text to add to the scheduled tasks
- `tests/` — automated checks (`node tests/backend.test.js`, `node tests/ui.test.js`)

To try it without setting anything up, open `app/index.html?demo=1`. The demo uses sample data only.
